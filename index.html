🚀 部署指南 3 分钟拿到公网链接
  1. 注册 GitHub 账号 github.com → 点 New repository 新建仓库，命名 ganzhou-trip，选 Public
  2. 把本文件改名为 index.html，在仓库页点 Add file → Upload files 上传
  3. 仓库页 → Settings → Pages → Source 选 main 分支 → Save
  4. 等 1-2 分钟，访问 你的用户名.github.io/ganzhou-trip 即完成 🎉
  5. 点亮地图：去 lbs.amap.com 免费申请 Web端(JS API) Key + 安全密钥，填入本文件顶部 CONFIG 中的两引号内，重新上传即可
